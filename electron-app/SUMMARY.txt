═══════════════════════════════════════════════════════════════
  🚀 如何使用
═══════════════════════════════════════════════════════════════

步骤 1: 安装依赖

  Windows: 双击 install.bat
  macOS/Linux: ./install.sh

  或手动:
  $ cd electron-app
  $ npm install

步骤 2: 开发运行

  $ npm run electron:dev

  应用将启动 Electron 桌面窗口

步骤 3: 构建打包

  $ npm run electron:build

  打包完成后，Windows 安装包位于 release/ 目录

═══════════════════════════════════════════════════════════════
  🎨 如何修改 UI
═══════════════════════════════════════════════════════════════

所有 UI 组件位于: src/renderer/components/

修改样式:
  - Announcement.css     → 公告栏样式
  - FileSettings.css     → 文件设置样式
  - BackupSettings.css   → 备份设置样式
  - BackupList.css       → 备份列表样式
  - StatusBar.css        → 状态栏样式

修改组件:
  - Announcement.tsx     → 公告栏逻辑
  - FileSettings.tsx     → 文件设置逻辑
  - BackupSettings.tsx   → 备份设置逻辑
  - BackupList.tsx       → 备份列表逻辑
  - StatusBar.tsx        → 状态栏逻辑
